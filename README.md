# number-guessing-game
A simple Python number guessing game I built while learning Python.

## Features
- Random number generation
- Multiple guesses
- High/low hints
- Attempt counter
- Player ranking system
- Replay option

## How to Run
1. Install Python
2. Clone this repository
3. Run:

python number_guessing_game.py
